# 두 계정 거래 채팅 데모

저장소의 로그인·예약 기능이 구현되기 전에 CHAT-01~02를 검증할 수 있는
독립 데모입니다. Python 3.10 이상과 기본 라이브러리만 사용합니다.
서버는 로컬 접속(`127.0.0.1`)만 허용합니다.

## 실행

저장소 루트에서 다음 명령을 실행한 뒤 일반 창과 시크릿 창에서
http://127.0.0.1:8000 을 각각 엽니다.

```powershell
py chat-demo/server.py
```

macOS/Linux에서는 `python3 chat-demo/server.py`를 실행합니다.

| 사용자 | 아이디 | 비밀번호 |
| --- | --- | --- |
| 대여자 A | renter | chat-demo123 |
| 소유자 B | owner | chat-demo123 |

1. 일반 창은 A, 시크릿 창은 B로 로그인합니다.
2. 두 창에서 **2인용 텐트**를 선택합니다. A가 “토요일 오후 2시에 받을 수 있을까요?”를 보냅니다.
3. B가 문의를 확인하고 “네, 정문에서 뵐게요!”라고 답장합니다. 상대 창을 약 1초 간격으로 갱신합니다.
4. 새로고침해도 이전 메시지가 남아 있는지 확인합니다. **미러리스 카메라**로 바꾸면 별도 대화가 표시됩니다.

## 구현 범위

- 시작할 때 데모 계정 두 개와 확정된 거래 두 건을 만듭니다.
- 서버가 세션과 거래 참여 여부를 확인하고 메시지를 SQLite에 저장합니다.
- 응답 유실 후 같은 요청을 다시 보내도 메시지는 한 건만 저장합니다.
- DB는 `chat-demo/chat.sqlite3`에 저장되며 Git에 포함되지 않습니다.
- 팀 프로젝트에 연결할 때 데모 계정 대신 팀의 인증과 거래 데이터를 사용해야
  합니다. 첨부·알림·AI 추천 채팅은 이 데모 범위에 포함되지 않습니다.

## 자동 검증

```powershell
py -m unittest discover -s chat-demo -p "test_*.py"
```

macOS/Linux에서는 위 명령의 `py`를 `python3`으로 바꿉니다.
