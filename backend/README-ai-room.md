# 렌토 AI 전용 채팅방

홈의 ‘AI에게 물어보기’에서 `#assistant` 화면으로 이동합니다. 용도·예산을 질문하고,
이전 대화를 참고한 후속 질문을 할 수 있습니다. 추천 물품은 실제 목록의 이름·가격·상세 링크로 표시합니다.
사용자 간 거래 채팅에서는 AI 패널과 호출을 제거했습니다. 거래 채팅 메시지와 거래 상태는 이 기능으로 변경하지 않습니다.

## Windows 실행

Ollama와 `qwen2.5:3b`를 이미 설치했다면 프로젝트 폴더에서 아래 명령을 각각 실행합니다.

```cmd
set CHAT_AI_MODEL=qwen2.5:3b
py backend/chat_server.py --port 8001
```

http://127.0.0.1:8001 에서 Ctrl+F5를 누르고 홈의 AI 버튼을 선택합니다.
기존 서버가 켜져 있으면 해당 창에서 Ctrl+C 후 재실행합니다. Flask 사진 비교 서버에도
같은 `/api/ai-room` 경로가 추가되어 있습니다. 사진 비교 서버의 별도 의존성은 기존과 같습니다.

## 사용 흐름

1. ‘집에서 영화 볼 때 쓸 물건 추천해 주세요’처럼 질문합니다.
2. AI 답변과 추천 물품 카드를 확인합니다.
3. ‘하루 예산은 5천 원이에요’처럼 이어서 질문할 수 있습니다.
4. 물품 카드를 누르면 상세 화면으로 이동합니다. 날짜와 조건을 확인하고 직접 신청합니다.
5. 답변 실패 시 질문이 입력창에 복원됩니다. ‘다시 보내기’를 누를 수 있습니다.
6. ‘새 대화’는 현재 AI 대화만 초기화합니다. 일반 거래 채팅은 지우지 않습니다.

Enter로 전송, Shift+Enter로 줄바꿈합니다. 한글 입력 조합 중 Enter는 전송하지 않습니다.
질문은 500자, 답변은 600자, 한 대화는 최대 10회 질문·답변입니다. 긴 대화는 새 대화로 시작합니다.
대화는 탭 메모리에 데모 프로필별로 분리하며 페이지 이동 후 복원됩니다. 새로고침·탭 종료 시 초기화됩니다.

## 데이터와 한계

- 전송 데이터: AI 채팅방의 성공한 이전 문답과 현재 질문, 사용자 본인 소유를 제외한 공개 물품 정보, 기준일.
- 전송하지 않는 데이터: 일반 사용자 간 채팅, 거래 내역·사진·비밀번호.
- 목록은 최대 30개, JSON 설명 합계 8,000자입니다. 제한 초과는 명시적으로 안내하며 몰래 생략하지 않습니다.
- 물품 카드의 ID는 제공 목록에 존재하는지 서버와 화면에서 검사합니다. 금액과 링크는 실제 목록으로 렌더링합니다.
- 추천 관련성·답변의 정확성은 모델 품질에 따라 달라집니다. 원문과 물품 상세를 확인해야 합니다.
- 대여 가능 안내는 기준일의 참고 정보입니다. 희망 날짜의 예약 가능 여부는 상세 화면에서 확인합니다.
- Ollama는 localhost:11434, Python 서버는 localhost에 연결합니다. AI는 예약·결제·전송·상태 변경 도구를 갖지 않습니다.
- 느린 모델 응답은 180초 후 오류를 안내합니다. 실행 오류는 서버의 CHAT_AI 로그를 확인합니다.
- 거래 채팅용 이전 API는 닫혀 있고, AI 요청은 전용 채팅방에서만 보냅니다.
- 실제 다중 사용자 로그인 인증과 서버 저장은 기존 프로필 전환 데모와 별도 작업입니다.

## 검증

```cmd
py -m unittest discover -s backend -p "test_*assistant.py" -v
```

입력 한도, 대화 맥락 전달, 존재하지 않는 물품 ID 거부, 출처·동시 요청 제한 등을 모의 응답으로 검사합니다.
실제 모델의 추천 품질과 사용자 PC 응답 속도를 보장하는 검사는 아닙니다.
