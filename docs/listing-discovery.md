# 물품 탐색·등록 지원 · 왕준서

성진욱이 구현한 기본 정보 → 사진 촬영 → 대여 조건 화면을 사용합니다. 등록 단계에서 직접 촬영한 사진과 대표 사진을 유지합니다.

## 보증금

대여 조건 화면에서 현재 중고 가액과 비교 거래 링크 또는 가격 판단 근거를 입력합니다. 가액 증빙은 확인 대기 상태로 저장됩니다. 개인 계정에서 예전 게시물에 가액이 없으면 게시한 사람이 상세 화면에서 가액과 근거를 추가할 수 있습니다. 이전 게시물의 수동 보증금을 새 거래에 사용하지 않습니다. 과거 거래에 저장된 금액은 유지합니다. 가액과 보증금 정책이 기록되지 않은 예전 승인 대기 신청은 가액 추가와 정책 적용 후 새로 신청해야 합니다.

서버 기본 정책 `rento-demo-v2`는 현재 중고 가액의 30%를 원 단위로 반올림하고 최대 200,000원을 적용합니다. 별도 최저액은 없습니다. 가액에 비례해 담보를 두되 고가 물품도 초기 부담을 제한하는 시연 기준입니다.

별도 환경에서 정책을 시험할 때는 서버의 `RENTO_DEPOSIT_POLICY`에 아래 필드를 가진 JSON을 설정합니다.

| 필드 | 값 |
| --- | --- |
| `version` | 정책 변경 시 바꾸는 정책 버전 |
| `rateBps` | 보증금 비율을 베이시스 포인트로 표현한 정수 |
| `minWon` | 원 단위 최소 보증금. 제한이 없으면 `null` |
| `maxWon` | 원 단위 최대 보증금. 제한이 없으면 `null` |

등록·상세 화면에 정책을 표시하고 서버에서 계산을 검증합니다. 새 거래에 적용한 정책의 버전과 금액이 거래에 함께 저장됩니다.

팀원 2는 `rentals/{id}`의 `total`(기본 대여료), `deposit`(확정에 사용한 보증금), `itemValue.amountWon`(거래 당시 중고 가액), `itemValue.evidence`, `depositPolicy.version`을 사용합니다. 새 거래를 신청하는 순간의 값이 저장되며 서버는 이후 변경을 거부합니다. 이전 거래에는 `itemValue`와 `depositPolicy`가 없을 수 있습니다.

## 물품 추천

검색어 전체 일치, 지정 분류, 하루 예산, 선택한 기간의 대여 재고를 먼저 검사합니다. 홈에서 날짜를 지정하지 않으면 오늘 대여 가능한 물품을 앞에 배치하고, 기타 물품은 상태를 표시해 탐색할 수 있습니다. 다른 사용자가 예약하면 다음 Firestore 갱신에 맞춰 홈 목록과 표시가 갱신됩니다. 실제 계정 모드에서는 전체 예약의 물품과 기간 정보만 사용하고 거래 참가자의 ID와 대화는 공유하지 않습니다.

후보의 점수는 물품명 검색어 일치 40점, 같은 동네 20점, 내 관심 물품 12점, 같은 분류 관심 및 완료 대여 이력 각각 5점(최대 15점)입니다. 점수가 같으면 일일 대여료와 물품 ID 순서로 정렬합니다. 이용 이력이 없으면 검색 일치와 동네가 순서를 정하고, 같은 조건에서 결과가 재현됩니다.

팀원 3은 `frontend/src/listing-recommendations.js`의 `recommendationCandidates(context)`를 사용합니다. `context.filters`에는 `query`, `category`, `maxPrice`, `date.start`, `date.end`를 전달합니다. 함수는 대여 가능한 후보를 최대 12건 반환하며 `id`, `price`, `availability`, `score`, `reasons`를 포함합니다. 기존 AI 채팅 요청에도 같은 결과를 전달합니다.

## AI 등록 지원과 일일 대여료

물품명으로 분류와 수정 가능한 초안을 제안합니다. Python 서버에서 `GEMINI_API_KEY`를 설정하면 AI 추천 채팅과 같은 Gemini 모델(`GEMINI_MODEL`)을 사용합니다. Gemini 키 없이 로컬 모델을 사용하는 경우 `LISTING_AI_MODEL` 또는 `CHAT_AI_MODEL`로 Ollama 모델을 지정할 수 있습니다. 모델이 없거나 응답이 유효하지 않으면 화면에 규칙 기반 작성 예시라고 표시합니다. 모델과 규칙 예시는 대여료를 입력하지 않습니다.

등록의 대여 조건에는 하루 대여료, 보증금, 대여 가능 기간만 표시합니다. 두 금액의 ‘렌토 추천’을 누르면 별도 창에서 상태를 선택하고, 브랜드·모델명과 구매 시기·사용 이력은 필요할 때 입력합니다.

보증금 렌토 추천은 물품명 또는 모델명으로 중고나라의 공개 판매 게시물을 조회합니다. Gemini가 같은 모델의 완제품을 고르면 게시가 범위와 중앙값을 표시합니다. 판매 중인 사례가 없으면 동일 모델의 확인된 과거 게시 가격을 별도로 표시합니다. 비교 자료가 한 건이면 그 가격을 참고로 표시합니다. 근거가 없거나 과거 기록 한 건만 있으면 현재 중고 가액 직접 입력 항목을 펼칩니다.

하루 대여료는 업체의 24시간 대여료 또는 렌토의 등록 대여료를 비교합니다. 카테고리별 시연 게시물을 통해 등록·추천 흐름을 시험할 수 있습니다. 일반 비교 사례가 부족할 때 시연용 가격만 모아 별도로 표시합니다. 중고 가액 추천에는 시연 게시물을 사용하지 않습니다. 보증금 추천은 외부 중고 판매 게시 가격을 참고하고, 선택한 가액에 30%·최대 200,000원 정책을 적용합니다. 공급자가 비교 결과를 적용하거나 직접 값을 입력할 수 있습니다.

## 시험 사례

| 조건 | 확인 결과 |
| --- | --- |
| 중고 가액 8만 원, 20만 원, 100만 원 | 기본 보증금 24,000원, 60,000원, 200,000원 |
| 과거에 가액 없이 등록한 물품 | 본인만 가액과 근거를 추가 가능. 가액이 없으면 새 신청과 AI 추천 대상에서 제외 |
| 보증금 테스트 정책 변경 | 새 거래 견적만 변경되고 기존 금액 수정이 거부됨 |
| 이력 없는 계정, 공구 검색, 하루 5천 원 한도 | 날짜에 빌릴 수 있는 예산 내 물품을 선택하고 같은 동네를 우선함 |
| 같은 조건의 물품이 해당 날짜에 예약됨 | 홈의 날짜 검색과 AI 추천에서 제외됨 |
| 대여 비교 사례의 하루 요금이 40,000원과 50,000원 | 출처와 범위 및 중앙값 45,000원 표시 |
| 비슷한 사례가 한 건 이하 | 금액 없이 직접 입력 안내 |
| AI 모델 연결 실패 | 작성 화면이 규칙 기반 예시를 표시함 |
